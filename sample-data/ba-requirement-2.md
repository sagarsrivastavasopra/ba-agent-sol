# BA Requirement — REQ-002

**Title:** Improve approval process for high-value opportunities

**Requested by:** Raj BA
**Priority:** High

## Description
Currently opportunities above a certain value don't get properly reviewed
before closing. We need an approval step added so management can review
these before they go through.

## Scope
- Add an approval step for high-value opportunities
- Notify the right people when approval is needed
- Should work with our existing opportunity process

## Acceptance Criteria
- High-value opportunities require approval before closing
- Approvers are notified
- Process fits into existing workflow
